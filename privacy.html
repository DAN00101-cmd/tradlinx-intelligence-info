개인정보 및 Google 데이터 처리 안내

적용 도구: Tradlinx Intelligence Personal
작성일: 2026년 11월 2일

이용 목적과 접근 범위

운영자 개인의 해상물류·공급망 조사 결과를 Google Drive에 저장하고 다시 읽어 확인합니다. Google의 drive.file 권한을 사용하며, 사용자가 앱에 허용한 파일과 폴더 및 앱이 만든 파일을 대상으로 합니다. 계정의 전체 Drive를 읽는 권한은 요청하지 않습니다.

처리하는 정보

OAuth 인증 정보, 선택한 폴더 및 파일의 식별자·이름, 앱이 저장한 보고서·스프레드시트·수집 상태 데이터베이스를 처리합니다. 공개 기사 제목·발췌·링크와 한국어 정리 결과가 보고서에 포함됩니다.

저장과 외부 처리

인증용 클라이언트 정보와 갱신 토큰, 폴더 식별자는 운영자의 비공개 GitHub 저장소 암호화된 Secrets에 저장되어 자동 실행에 사용됩니다. 자동 실행은 Google API를 통해 지정된 파일을 읽고 씁니다. 수집 데이터와 보고서는 Google Drive에 저장되고, 복구를 위한 GitHub Actions 실행 산출물은 현재 90일 동안 보관하도록 설정되어 있습니다.

운영자가 별도로 연결하고 요청한 Codex 기능은 해당 Google 파일의 조사 자료를 읽어 한국어 정리를 작성할 수 있습니다. 이때 해당 서비스의 데이터 처리 설정이 적용됩니다. 현재 이 도구의 별도 유료 OpenAI API 연결은 사용하지 않습니다. 인증 비밀값은 보고서나 이 공개 안내 사이트에 게시하지 않습니다.

접근 해제와 삭제

운영자는 Google 계정의 연결된 앱 설정에서 권한을 철회하고 GitHub의 관련 Secrets와 자동 실행을 중지할 수 있습니다. 생성 파일은 Google Drive에서 삭제할 수 있으며, 실행 산출물은 GitHub에서 삭제하거나 보관 기한 만료를 기다릴 수 있습니다. 권한 철회만으로 기존 파일이 자동 삭제되지는 않습니다.
